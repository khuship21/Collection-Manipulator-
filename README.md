# Collection-Manipulator-
this  is a Python-based console application designed to manage, organize, and manipulate a collection of student records efficiently. This project demonstrates the application of intermediate-level Python programming concepts, including string formatting, data manipulation, and collection data types such as Lists, Tuples, Sets, and Dictionaries.

The program allows users to add, update, search, delete, and display student data in a structured and user-friendly manner. It also highlights the difference between mutable and immutable data types, the use of type casting for data conversions, and the implementation of the del keyword for data removal.

This project serves as a practical example of how Python’s data structures can be used to build real-world data management applications.

----------------Key Features-----------------

- Add, update, and delete student records dynamically

- Display student data in a formatted and organized manner

-  Demonstrate the use of Lists, Tuples, Sets, and Dictionaries

-  Apply mutability and immutability concepts in data management

-  Implement type casting between data types

-  Use the del keyword for record deletion


----------------Concepts Demonstrated-------------------
- String formatting and manipulation  
- Collection data types: List, Tuple, Set, Dictionary  
- Mutability and immutability  
- Type casting  
- Use of the `del` keyword  
- Loops and control structures for user input
